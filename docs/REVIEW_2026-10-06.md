### J-N2 · Variable names: APPLIED, option B (2026-10-06)
Renamed: `--w-regular` / `--w-semibold` → `--fw-regular` / `--fw-semibold`; `--t-h1 … --t-micro` → `--fs-h1 … --fs-micro`. This frees `--w-*` for widths and removes the `--t-*` / `--text-*` confusion. Updated in tokens, text styles and every active document; older changelog entries keep the old names (rename table at the top of the changelog).
**Not applied (option C, available on request):** `--surface-sunken` → `--surface-muted`, `--surface-glass` → `--surface-overlay`, `--surface-chip-on-photo` → `--surface-on-photo`, `--surface-dark/-dark-2` → `--surface-inverse/-inverse-strong`, `--text-faint` → `--text-decorative`, `--text-on-dark*` → `--text-on-inverse*`, `--accent-strong*` → `--action*`, `--star` → `--rating`. They are appearance-leaning but unambiguous; renaming them is cheap before the build and costly after.
