# Audit: Guadeloupe v12 vs design system (2026-10-06)

> **Historical rationale.** Token and style names in this file (`--t-display-l`, `--t-input`, `t-ui`…) were superseded the same day by `TYPOGRAPHY.md`. For current values read `tokens.css`, `TYPOGRAPHY.md` and `COMPONENTS.md`. The open decisions J1–J8 below remain valid.

Scope: `Guadeloupe v12 Details.dc.html` (listing, destination, blog article, blog index, filter page, guide page, privacy), `Guide Offer Card.dc.html`, `tokens.css`, `DESIGN_SYSTEM.md`.
Method: static analysis of every style in the file (counts per view), contrast calculation for every text/surface pair, and a mobile-first read of each layout at ~360px. **Not done:** no real-device test and no screenshot review at 360px; items marked "verify" below must be checked on a phone before launch.
Missing for a complete audit: nothing blocking. Not in the project and therefore not audited: the footer's final markup beyond what the file contains, any 404/empty states, and English pages.

Legend: **S→DS** = the site should change to match the system. **DS→S** = the system was updated to match a better pattern already on the site. **J** = judgment call, options in §5.

## 1. What changed in the system (summary)
- `tokens.css` rewritten: every variable now has a role comment; added spacing scale, layout, breakpoints, z-index, motion, focus, status, text-on-dark steps, line heights, `--target`. Stale values fixed (`--article-gap`, `--w-article`, `--accent` use, `--danger`).
- New `text-styles.css`: one class per text role + global focus, reduced-motion, keyframes.
- `DESIGN_SYSTEM.md` §1 rewritten as a usage guide (when to use each variable). Mobile-first principles and rules for states and accessibility added. Outdated parts of §2 and §3 corrected.

## 4. UX improvement opportunities (judged mobile-first; verify on device)
1. **Listing, first screen on phone:** hero + sticky filter bar + safety banner stack before the first card. Collapse the banner by default to its "Sécurité" pill after the first visit, and make the filter row two controls (J2).
2. **Destination, first screen:** the key facts sit in a grid after the hero; the only booking entry is a sticky bottom bar that hides on scroll-down. Keep, but ensure the bar never covers the "Avec un guide" link.
3. **Facts (M1):** biggest readability gain for tour pages; 2-column cells give values room to wrap.
4. **Bon à savoir tiles, nearby cards, press list:** all have 44px rows; good.
5. **FAQ:** 17px questions with a "+" glyph: good; add `aria-expanded` via `<details>` (native, already).
6. **Reading blocks:** destination prose now uses the reading face: check line length on tablet (680px cap works).
7. **Emoji icons (13 types):** render differently per OS. **J5.**

## 5. Judgment calls (options, my recommendation marked)
- **J1 · Fact strips on mobile.** A) 2 columns below 480px, one row per ≤4 cells above (recommended: values wrap, rhythm stays a grid). B) Horizontal scroll row (keeps today's look, hides cells). C) Stack as label/value rows (most readable, tallest).
- **J2 · Filters on mobile.** A) Search + one "Filtres" button opening the sheet; inline pills ≥1024 (recommended: fewer targets, the sheet already exists). B) Keep the scrolling row and add a leading "Filtres" button. C) Keep as is.
- **J3 · Where does "signature" live.** Now only the card subtitle. A) keep as is (recommended). B) Show again in Aperçu as the reading-face line. C) Remove the field.
- **J4 · Article gutter.** A) 20 and 24 as now (recommended: reading comfort). B) 20 everywhere (simpler).
- **J5 · Emoji icons.** A) Keep (cheap, warm, a brand trait; documented as decorative) (recommended). B) Replace by one line-icon set (consistent rendering, +1 dependency, loses warmth).
- **J6 · Listing H1.** A) `--t-display-l` clamp 34→44 (recommended: one H1 scale). B) Keep 38px fixed.
- **J7 · "en sécurité" copy.** A) "Y aller avec un guide" / "Voir la sortie" (recommended). B) Keep and soften to "Y aller accompagné".
- **J8 · Yalodé teal.** #0A8577 is 4.53:1 on white (passes by 0.03). A) Keep, ≥14px/600 only (recommended). B) Darken to #087A6D (5.2:1) for small text safety.
